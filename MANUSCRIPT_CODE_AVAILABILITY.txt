Code Availability

Source code, fixed configurations, benchmark-reconstruction workflows, the canonical MSRR implementation, evaluation scripts, and reproducibility/reference materials are publicly available at https://github.com/neon-wolf9/MSRR-landslide, release v1.0.0. The corresponding immutable software release will be archived on Zenodo at [ZENODO_DOI]. Third-party EO/GIS source data are not redistributed; acquisition instructions, product identifiers, expected directory structures, and reproducibility guidance are provided in the repository.
