# Code Availability — Computers & Geosciences final draft

The source code, fixed configurations, benchmark-reconstruction workflows, canonical implementation of Matched-Set Relative Representation (MSRR), evaluation and statistical-inference scripts, and reproducibility/reference materials supporting this study are publicly available at https://github.com/neon-wolf9/MSRR-landslide under release v1.0.0. An immutable archived release will be deposited with Zenodo at [ZENODO_DOI].

The repository includes redistribution-safe schemas, provenance manifests, exact benchmark-replay evidence, synthetic demonstration data, and frozen numerical reference outputs. Third-party Earth-observation, GIS, and source-inventory data are not redistributed. Their providers, exact products and versions, native supports, event-specific snapshots, official acquisition pages, expected local paths, and redistribution constraints are documented in the repository. Full reconstruction therefore requires users to obtain those inputs from the original providers and comply with the applicable terms.

The synthetic demonstration and redistribution-safe verification suite can be run without the Hiroshima or Kyushu source data. The released code preserves the scientific definitions, matching protocol, fold assignments, MSRR construction, model configurations, external-event protocol, and manuscript reference results used in the study.

Before submission or publication, replace [ZENODO_DOI] with the verified archive record; do not remove that placeholder until the record exists.
