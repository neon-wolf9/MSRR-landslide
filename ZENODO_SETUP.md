# Zenodo archival setup

1. Publish the reviewed GitHub repository.
2. Create the GitHub release `v1.0.0` from the exact validated commit.
3. Connect the public GitHub repository to Zenodo using the authors' Zenodo account.
4. Enable archiving for the repository and archive the `v1.0.0` release.
5. Verify the archived file list, authors, title, license, version, and related manuscript metadata.
6. Record the version-specific Zenodo DOI.
7. Replace the DOI placeholders in the manuscript Code Availability text and add the real DOI to repository citation metadata.
8. Do not reuse a concept DOI where the journal requires the immutable version-specific DOI.

No Zenodo record or DOI has been created by this repository-preparation task. Do not replace placeholders until the public archive exists and has been verified.
