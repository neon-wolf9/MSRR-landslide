# Frozen configuration records

- `matching/`: variable dictionary, normalization, feasibility, distance, common-support, tie, and optimization records.
- `features/`: formal representation dimensions and experiment-119 selection records.
- `learners/`: experiment-120B run manifest and validation-only selections.
- `experiments/`: preregistrations and run configurations for placebo, comparators, PairDiff, and robustness analyses.
- `external/`: Kyushu provenance, feature whitelist, leakage blacklist, frozen protocol, and deployment selection.
- `benchmark/`: intentionally contains only this package-level note; historical development YAML files were not part of the final MSRR authority chain and were excluded.
