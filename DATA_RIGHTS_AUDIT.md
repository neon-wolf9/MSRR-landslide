# Data-rights audit — release candidate, 2026-10-21

Scope: the seven **derived** files needed by the Hiroshima/Kyushu model-ready workflows. This is a provenance and licence-evidence audit, not legal clearance for all source products or authorization to upload data. The original project was read only. A separate unpublished local candidate contains only the author-generated 1:2 integer-position array of the seven; the public code package excludes that array pending final sign-off. `NEEDS RIGHTS REVIEW` means that a file is not yet cleared for public deposit, **not** that redistribution is prohibited.

## Provider-level licence evidence (not file-level clearance)

- [AJG Hiroshima fourth report](https://www.ajg.or.jp/disaster/files/201807_report004.pdf), section 6: CC BY 4.0 with the stated Hiroshima University research-group credit. Confirm that the actual frozen label source is this edition.
- [GSI terms](https://www.gsi.go.jp/ENGLISH/page_e30286.html): normally PDL 1.0 with source/modified-data citation; third-party material and Survey Act exceptions require product-specific checking. The English page itself says its Japanese version is authoritative.
- [Copernicus DEM GLO-30 licence](https://documentation.dataspace.copernicus.eu/APIs/SentinelHub/Data/DEM/resources/license/License-COPDEM-30.pdf), [ISRIC SoilGrids policy](https://docs.isric.org/globaldata/soilgrids/SoilGrids_faqs_02.html), [USGS Landsat guidance](https://www.usgs.gov/media/images/landsat-product-citation-screenshot), [CLMS policy](https://land.copernicus.eu/en/data-policy), and [GSJ terms](https://gbank.gsj.jp/seamless/agreement_en.html) each provide reuse routes, with product/source credit and modification notices where required. Match the frozen version before relying on a policy.
- [OSM legal guidance](https://wiki.openstreetmap.org/wiki/Legal_FAQ) identifies ODbL attribution/share-alike obligations for a Derivative Database. Whether these 92-feature tables meet that definition is unresolved; do not automatically apply the MIT code licence to them.
- [J-FlwDir product page](https://hydro.iis.u-tokyo.ac.jp/~yamadai/JapanDir/index.html) states CC BY 4.0 and asks users not to repost the complete original-format dataset without written permission. That request does not establish a ban on the small derived hydrology features.
- [NASA Earthdata data-use policy](https://www.earthdata.nasa.gov/engage/open-data-services-software/data-use-policy) says unmarked NASA-led data are CC0, while marked restrictions control. The [GPM mission policy](https://gpm.nasa.gov/data/policy) says GPM products are freely available and requests product citation. This is strong provider-level support for sharing IMERG-derived values, but the exact collection use-constraint/credit record and the source-product identity frozen by this project still need matching; a login requirement is not itself a redistribution ban.

Before any upload, record for each proposed file: frozen source identity and acquisition date, upstream licence/exception, required credit and licence text, who owns the derived compilation, whether separate consent is needed, and a final yes/no deposit decision. Six of seven files remain **NEEDS RIGHTS REVIEW**; none of those six is in the candidate. The positional array is prepared locally, not published.
